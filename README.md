# QR Screen Reader

Windowsの画面・クリップボード・画像ファイルから、QRコードの内容を確認できるデスクトップアプリです。

スマートフォンを使わず、画面内のQRコードをマウスで範囲選択して、格納された文字列やURLを読み取れます。

AI（ChatGPT / Codex）を活用して開発しています。現在は試用版です。

## ダウンロード・起動

1. [Releases](https://github.com/nagi3x9/qr-screen-reader/releases)を開きます。
2. Assetsにある **QRScreenReader.zip** をダウンロードします。
3. ZIPを右クリックし、「すべて展開」で展開します。
4. 展開したフォルダ内の **QRScreenReader.exe** を起動します。

**アプリのインストールや、利用時のPythonのインストールは不要です。**

exeと `_internal` などの同梱ファイルは、同じフォルダに置いたまま使ってください。exeだけを取り出すと動作しません。

Releasesの「Source code (zip)」「Source code (tar.gz)」は開発用です。アプリを使う場合は **QRScreenReader.zip** を選んでください。

## 主な機能

- ショートカットキーによる画面の範囲選択
- クリップボード画像からのQRコード読み取り
- ローカル画像ファイルからのQRコード読み取り
- 読み取った文字列の表示・コピー
- HTTP／HTTPSのURLを確認後にブラウザで開く
- 直前の方法で再読み取り
- 専用のQRモチーフアイコン

## 使い方

### 画面から読み取る

1. アプリを起動します。
2. 読み取りたいQRコードを画面に表示します。
3. **Ctrl + Shift + Q** を押すか、アプリの「画面から読み取り」をクリックします。
4. 暗い選択画面が表示されたら、QRコードを囲むようにマウスでドラッグします。
5. マウスを離すと解析が始まり、読み取り結果が表示されます。

QRコードの周囲にある白い余白も含めて選択すると、読み取りやすくなります。

範囲選択をキャンセルする場合は **Esc** を押してください。

アプリを最小化していてもショートカットキーを使用できます。アプリを終了すると、ショートカットキーも解除されます。

### クリップボードから読み取る

1. Windowsのスクリーンショット機能などで、QRコードを含む画像をコピーします。
2. アプリの「クリップボード」をクリックします。
3. 読み取り結果を確認します。

クリップボードに画像がない場合は、メッセージを表示します。

読み取るだけでは、クリップボードの内容を上書きしません。

### 画像ファイルから読み取る

1. 「画像ファイル」をクリックします。
2. QRコードを含む画像を選択します。
3. 読み取り結果を確認します。

対応形式は **PNG・JPG／JPEG・BMP・WebP** です。

### 読み取った文字列をコピーする

読み取り結果を確認して、「コピー」をクリックします。

改行も含めて元の文字列をコピーします。制御文字が含まれる場合、貼り付け先によって表示や動作が異なることがあります。

### URLを開く

読み取り結果が、アプリの検証条件を満たすHTTP／HTTPSのURLだった場合のみ、「URLを開く」が有効になります。

ボタンをクリックし、確認ダイアログに表示されたURLを確認してから開いてください。

URLを自動的に開くことはありません。`javascript:`・`file:`・`data:` などのスキームは、ブラウザ起動の対象にしません。

URLの形式を確認する機能であり、リンク先の安全性を保証するものではありません。

### 再読み取りする

「再読み取り」をクリックすると、直前と同じ読み取り方法を開始します。

画像ファイルから読み取った場合は、ファイル選択画面が再び開きます。

## プライバシー

- QRコードの解析はPC内で行います。
- 画像や読み取った内容を外部サーバーへ送信しません。
- 読み取り履歴を自動保存しません。
- 取得した画像を自動保存しません。
- QRコードの内容をアプリのログに記録しません。
- 常時画面監視は行わず、範囲選択を開始したときだけ画面を取得します。
- 読み取りはインターネット接続なしで利用できます。

読み取り結果は、次の読み取りやアプリ終了までメモリ上に保持されます。

コピーした情報はWindowsのクリップボードに残ります。Windows側のクリップボード履歴・同期を有効にしている場合は、OSの設定に従います。

「URLを開く」を使用した場合は、ブラウザによる通常のネットワーク通信が発生します。

## 対応環境・検証状況

**Windows 10／11の64bit環境を対象**としています。すべての環境での動作を保証するものではありません。

開発者のWindows環境では、ビルドしたexeの起動と、画面からの読み取りが動作したとの確認があります。

開発環境での自動テスト・模擬テストは38件成功しています。ただし、自動テストの成功は、Windows実機のすべての操作や環境での動作を保証するものではありません。

次の項目は、引き続き実機での確認が必要です。

- Windows 10／11それぞれでの動作
- 125％・150％などのディスプレイ倍率
- 異なる倍率が混在する複数モニター環境
- モニターの接続・切断や配置変更
- 他のアプリとのショートカットキー競合
- Python未導入の別PCでの起動
- すべての入力方法とエラー後の再操作
- 多様なQRコード画像での読み取り精度

開発時の検証記録は `TEST_RESULTS.md`、制限や未検証項目は `KNOWN_ISSUES.md` を参照してください。これらには、各版の作成時点の記録も含まれています。

## Windowsの警告について

exeには発行元を証明する電子署名がありません。そのため、Windowsで発行元に関する警告が表示される場合があります。

署名がないことだけで悪意のあるファイルと判断されるわけではありませんが、安全性が保証されるわけでもありません。入手元を確認し、必要に応じてMicrosoft Defenderなどで検査してください。

## うまく読み取れない場合

### QRコードを検出できない

- QRコード周囲の白い余白も含めて選択してください。
- QRコードを大きく表示してから読み取ってください。
- 画像がぼやけていないか確認してください。
- 画面から読み取れない場合は、スクリーンショットを使い、クリップボードや画像ファイルからの読み取りも試してください。

破損・低解像度・強い変形などにより、読み取れない場合があります。

### ショートカットキーを使えない

他のアプリが **Ctrl + Shift + Q** を使用している可能性があります。

ショートカットキーの登録に失敗した場合も、アプリの「画面から読み取り」ボタンから操作できます。

### 黒いコマンド画面が表示される

通常利用では、`start_windows.bat` ではなく **QRScreenReader.exe** を起動してください。

`start_windows.bat` はソースコードから起動するための開発用スクリプトです。

### exeが起動しない

- ZIP内から直接起動せず、すべて展開してください。
- exeと `_internal` などが同じフォルダにあるか確認してください。
- exeだけを別の場所へ移動していないか確認してください。

デスクトップから起動したい場合は、exe本体を移動せず、ショートカットを作成してください。

## 制限

- 複数QRコードの同時読み取りは保証していません。
- 自動起動・システムトレイ常駐・読み取り履歴の機能はありません。
- ショートカットキーは現在、Ctrl + Shift + Qです。
- QRコードのデータを正確な文字列として復元できない場合は、エラーを表示します。
- QRコードの内容がURLでも、検証条件を満たさない場合は「URLを開く」を無効にします。
- リンク先の安全性や、読み取った内容の信頼性を判定する機能はありません。

## ソースからビルドする

**配布用ZIPからアプリを利用するだけなら、この作業は不要です。**

### 必要なもの

- Windowsの64bit環境
- Python 3.12（64bit）
- Python Launcher（`py`）
- 初回の依存ライブラリ取得用のインターネット接続

### ビルド手順

1. ソースコードをダウンロードし、展開します。
2. Python 3.12（64bit）をインストールします。
3. `build_windows.bat` を実行します。
4. 「Build succeeded」と表示されたら、次のexeを起動します。

```text
dist/QRScreenReader/QRScreenReader.exe
```

管理者権限は原則不要です。自分が書き込めるフォルダで実行してください。

ビルドが失敗した場合は、コマンド画面に表示されたエラーを確認してください。

### 配布用ZIPを作る

生成された **`dist/QRScreenReader` フォルダ全体**を圧縮してください。

exe・`_internal`・README・ライセンスなどの同梱ファイルを残してください。開発用の `.venv` や `build` フォルダを配布する必要はありません。

### ソースから起動する

ビルドスクリプトで作成した環境を使い、`start_windows.bat` から起動できます。

### 更新する

ソースから作り直す場合は、起動中のアプリを終了し、更新したソースで `build_windows.bat` を再実行してください。

生成された新しいexeを起動してください。既存の配布用フォルダを更新する場合も、アプリを終了してからフォルダ一式を入れ替えてください。

## 技術構成

| 用途 | 技術 |
| --- | --- |
| 開発言語 | Python 3.12 |
| GUI・クリップボード | PySide6 6.8.3 |
| QRコード解析 | ZXing-C++ 2.3.0 |
| 画像処理 | Pillow 11.3.0・NumPy 2.2.6 |
| 画面取得・モニター配置 | Windows API |
| グローバルショートカット | Windows APIのRegisterHotKey |
| exe作成 | PyInstaller 6.16.0 |

OpenCVは開発時の比較用に使用しており、アプリの実行時依存には含めていません。

通常は元の画像で解析し、失敗した場合のみ余白追加・グレースケール化・コントラスト調整・拡大を試します。

画像ファイルの読み込みとQR解析は別スレッドで行います。範囲選択開始時の画面取得はGUI側で行います。

## 開発・テスト

```bat
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest -q
```

テスト画像の生成：

```bat
.venv\Scripts\python generate_samples.py
```

QR解析ライブラリの比較：

```bat
.venv\Scripts\python compare_decoders.py
```

テスト画像は `test_images` にあり、期待する内容は `test_images/expected.json` に記載しています。

`decoder_comparison.json` は比較時の結果です。限られたテスト画像での結果であり、すべての画像に対する認識率を示すものではありません。
